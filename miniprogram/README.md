# 打卡助手 · 微信小程序代码包

喝水打卡 + 饮食记录 + 晨起体重记录，数据保存在本机 Storage，不联网。

## 目录结构

```
miniprogram/
├── app.js / app.json / app.wxss      # 全局入口与样式
├── project.config.json                # 项目配置（AppID 需替换）
├── sitemap.json
└── pages/
    └── index/                         # 首页：喝水、饮食、体重、提醒、7 天历史
```

## 导入步骤（开发者工具）

1. 打开**微信开发者工具**，选择「导入项目」。
2. 项目目录选择本 `miniprogram` 文件夹。
3. AppID 填写你自己的小程序 AppID（当前 `project.config.json` 中为占位 `touristappid`；无 AppID 可先选测试号）。
4. 编译即可预览；真机调试用「预览」扫码。

## 功能

- 喝水：150/200/250/300ml 杯量切换，一键记录、撤销、重置，可改每日目标，最近 7 天柱状图。
- 饮食：早餐 / 午餐 / 晚餐 / 加餐文本记录，晨起体重（斤）记录，按日期自动保存。
- 提醒：前台打开时按间隔弹窗提示喝水。

## 说明与限制

- 提醒为**小程序前台本地计时**；退到后台或离线后，微信会挂起定时器，无法推送。若需要后台/离线订阅提醒，需在小程序后台开通「订阅消息」并配合自己的服务端下发，本代码包未包含该后端部分。
- 所有记录仅存于当前设备本地，卸载或清除缓存会丢失，不做云端同步。
- 饮食记录仅作自我观察工具，请注意均衡摄入，避免过度节食；出现持续头晕、心慌、乏力请及时进食休息，必要时就医。
